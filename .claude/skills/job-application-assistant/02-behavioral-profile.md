# Behavioral Profile

## Overview
Layla's behavioral profile is a **Builder-Analyst** pattern — someone who repeatedly creates operating systems and workflows from scratch, then uses research and data to improve them. High tolerance for ambiguity and parallel context-switching; currently manages 4–5 concurrent part-time roles.

## Core Behavioral Drives

| Drive | Level | Meaning |
|-------|-------|---------|
| Initiative | High | Builds from zero across every role — content platforms, LP reporting frameworks, event systems, automation scripts |
| Analytical rigor | High | Combines qualitative (user interviews, founder conversations) with quantitative (financial models, market sizing) |
| Communication output | High | Published writer at scale; translates complex technical topics for multiple audiences simultaneously |
| AI curiosity | High | Genuine ecosystem fluency spanning products, investment, community, and agentic tooling |

## Strongest Behaviors
- **Systems builder:** Creates repeatable workflows (content SOPs, publishing cadences, CRM frameworks, Codex automation) rather than one-off outputs.
- **Multi-audience translator:** Moves fluidly between technical AI content for builders, investment-oriented analysis for VCs, and GTM messaging for product teams.
- **Parallel operator:** Sustains quality output across multiple concurrent roles with distinct deliverable types.

## How You Work Best
- Fast-moving, cross-functional environments where building from scratch is expected
- Roles with clear output ownership (a content system, a research pipeline, a user insight report)
- Teams that value written communication and analytical depth
- Environments with genuine AI product exposure — not just "AI strategy" in name

## Growth Areas (frame positively in applications)
- **Depth vs. breadth:** Wide role portfolio demonstrates range; when targeting focused roles, lead with the specific track (investment, content, or product) rather than the full breadth. *[Inferred from CV patterns — review before relying on this]*
- **Technical implementation:** Strong in AI-assisted workflows and automation (Claude Code / Codex); not a software engineer. Frame as "AI-fluent operator who ships" rather than developer.

## Mapping to Job Posting Language

When a job posting mentions these, it's a **strong behavioral fit**:
- "build from scratch", "0 to 1", "early stage", "generalist", "founder mindset"
- "cross-functional", "fast-paced", "ambiguous environment"
- "research", "analysis", "written communication", "content"
- "community", "events", "outreach", "BD"

When a job posting mentions these, flag as **potential friction**:
- "highly structured process", "large enterprise maintenance"
- "deep specialization in a single technical domain" (engineering, quant)

## Management Style Preferences
- Managers who give output ownership and let approach be self-directed
- Written communication preferred over meeting-heavy culture
- Values direct, honest feedback

## Using This in Applications
- **Cover letters:** Lead with the builder pattern — "I build systems, not one-off outputs." Quantify: 1,100+ LP CRM, 100k+ reads, 1,000+ attendee event.
- **CV:** Emphasize the creation arc in bullets: no system existed → built one → measurable result.
- **Interviews:** STAR examples should follow: problem → no existing system → built one → outcome.
- **Don't overstate:** Don't claim deep engineering or quant finance background. The value is AI-fluent operator who ships written and operational output at scale.
